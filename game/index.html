영호의 게임에뮬레이터

기종을 먼저 선택하면 전용 실행 페이지로 이동합니다. 게임 파일은 장치에서 직접 선택해 브라우저에서 실행합니다.

PC · 노트북 · 태블릿 · 스마트폰 대응·키보드 / 마우스 / 게임패드 입력 감지·전체화면 지원
1. 콘솔 / PC 선택
2. 실행 방식
기종을 누르면 다음 페이지에서 파일 선택 → 에뮬레이터 실행 순서로 진행됩니다. 콘솔 ROM은 EmulatorJS 계열 코어를 사용하고, MS-DOS / Windows 3.1 / Windows 95는 브라우저 x86 에뮬레이터(v86 계열)를 사용합니다.

배지 표시 · NEW: 이번에 추가된 기종 · BIOS: ROM과 함께 BIOS 파일을 한 번 더 선택해야 실행됩니다 · 실험적: 아직 완성 단계가 아닌 엔진이라 게임에 따라 실행이 안 될 수 있습니다 · 미지원: 브라우저에서 돌릴 수 있는 공개 코어가 아직 없는 기종입니다(아이콘을 누르면 이유가 표시됩니다) · iOS주의: iOS 사파리는 탭 메모리 제한(약 265MB)으로 이 기종이 버벅이거나 실행되지 않을 수 있습니다(안드로이드 Chrome은 정상 동작). 아이콘에 손가락을 올리면 자세히 볼 수 있습니다.

새턴 참고 — 세가 새턴(야바우제 코어)은 연산량이 많아 무거운 기기에서 느릴 수 있습니다. 실행 페이지에서 스레드 가속을 자동으로 켜며(https 주소 또는 localhost 필요), 실제 새턴 BIOS 파일을 추가하면 속도와 호환성이 더 좋아집니다.
영호 게임에뮬레이터 · 게임 파일은 서버에 업로드하지 않고 사용자의 브라우저에서 처리합니다. 본인이 소유하거나 합법적으로 이용할 권리가 있는 파일만 사용하세요.
