[나의 기록보관소] 사용 설명서

■ 꼭 필요한 것
이 사이트는 사진/영상/음악/메모 폴더의 내용을 자동으로 읽어오고,
게시판 글쓰기(사진 업로드 포함)도 되기 때문에 "PHP를 지원하는 웹 호스팅"에
올려야 정상적으로 동작합니다. (예: 닷홈, 카페24, 가비아 등 PHP 호스팅)
파일만 더블클릭해서 여는 방식(내 컴퓨터에서 바로 열기)으로는 목록 불러오기,
글쓰기 기능이 동작하지 않습니다.

■ 올리는 방법
1. 압축을 풀어서 나온 모든 파일과 폴더(index.html, css, js, api, data,
   PHOTO, VIDEO, MUSIC, MEMO, GPHOTO)를 웹 호스팅의 홈 폴더(예: html, www,
   public_html 등)에 그대로 업로드합니다.
2. data 폴더와 GPHOTO 폴더는 쓰기 권한이 필요합니다. FTP 프로그램에서
   두 폴더의 권한(퍼미션)을 707 또는 755로 설정해 주세요. (호스팅사마다 다를 수 있어요)
3. 브라우저에서 index.html 주소로 접속하면 아이콘 메뉴가 나타납니다.

■ 게시판 글쓰기 (네이버 붙여넣기)
게임 게시판의 글쓰기 화면은 흰색 캔버스 + 툴바로 된 리치 에디터입니다.
네이버 카페나 블로그의 글을 복사한 뒤 편집창에 붙여넣으면(Ctrl+V) 서식과
사진이 함께 들어옵니다. 글을 올리면 서버가 그 안의 사진을 전부 내려받아
GPHOTO 폴더에 저장하고, 글 속 사진 주소를 로컬 주소로 자동으로 바꿔줍니다.
(호스팅에서 allow_url_fopen 설정이 꺼져 있으면 외부 사진 내려받기가 안 될
수 있어요. 대부분의 호스팅에서는 기본적으로 켜져 있습니다.)

■ 폴더별 사용법
- PHOTO  : 이 폴더에 사진 파일을 올리면 '사진' 페이지에 자동으로 보여요.
- VIDEO  : 이 폴더에 영상 파일을 올리면 '영상' 페이지에 자동으로 보여요.
- MUSIC  : 이 폴더에 음악 파일을 올리면 '음악' 페이지에 자동으로 보여요.
           (mp3, wav, m4a 등은 바로 재생, midi 등은 다운로드 링크로 표시)
- MEMO   : 이 폴더에 txt/md 메모 파일을 올리면 '메모' 페이지에서 눌러서 읽을 수 있어요.
- GPHOTO : 게임 게시판에서 사진을 첨부해 글을 올리면 자동으로 저장되는 폴더예요.
           직접 파일을 넣지 않아도 됩니다.
