Windows 95 Web Emulator
=======================

구성
- winemu.html: v86 기반 Windows 95 웹 에뮬레이터
- images/Win95.zip: 서버에서 자동으로 내려받는 Windows 95 압축 이미지
  - ZIP 내부의 Win95.img를 브라우저에서 압축 해제하여 v86 HDA로 사용합니다.
- start_server.bat: 로컬 테스트 서버 시작용

서버 사용
1. winemu.html과 images/Win95.zip을 같은 pcemu 폴더 구조로 업로드합니다.
2. 브라우저에서 winemu.html을 엽니다.
3. '부팅'을 누르면 images/Win95.zip을 서버에서 받아 내부 Win95.img로 Windows 95를 시작합니다.
4. 서버가 다른 경로를 사용하는 경우 winemu.html에 준비된 대체 경로도 순서대로 시도합니다.

중요
- 서버가 HTTP Range를 반드시 요구하는 방식은 아니며 현재 페이지는 ZIP 전체를 fetch한 뒤 브라우저에서 압축을 풉니다.
- Dothome에서 CORS 정책 때문에 fetch가 차단되는 경우에는 서버의 동일 출처에서 페이지를 제공해야 합니다.
- 서버에는 Win95.img를 별도로 둘 필요가 없습니다. 현재 배포본은 images/Win95.zip 안에 Win95.img가 들어 있습니다.

폴더드라이브
- Windows 95가 실행된 뒤 메뉴의 '📁 폴더드라이브'를 누릅니다.
- PC/모바일에서 사용자가 직접 선택한 폴더를 읽습니다.
- 폴더의 파일과 하위 폴더를 FAT16 보조 HDD 이미지(128MB 고정)로 만들어 v86 HDB에 연결합니다.
- 현재 실행 상태를 저장한 뒤 같은 Windows 95 상태를 복원하면서 보조 HDD를 연결합니다.
- 연결 후 Windows 95에서 E: 보조 HDD를 G:로 자동 매핑하여 G:에서 폴더 내용을 볼 수 있게 합니다.
- 브라우저 보안상 사용자가 선택하지 않은 기기 폴더는 읽지 않습니다.
- 현재 폴더드라이브의 파일 데이터 총량 제한은 약 110MB입니다. 긴 파일명은 DOS 8.3 형식으로 저장됩니다.
- 브라우저/Windows 95의 상태에 따라 G: 매핑이 완료되는 데 잠시 걸릴 수 있습니다.

게임추가
- 기존 '게임추가'는 .img 파일을 플로피 A:에 연결하는 기능입니다.
